# Majhi Jaben?! — Python Source-Geometry Port (Milestone 1)

## What this package is

The `docs/` folder is a GitHub Pages-ready browser version of **Majhi Jaben?!**.
Rather than approximating the original Python visuals with unrelated cuboids, this release contains a binary scene mesh generated by *executing the rendering functions in the user-provided Python source* inside an offline OpenGL-geometry recorder (`tools/export_geometry.py`).

The exported scene contains the original building facades, campus, street props, trees, shops, cars, storm clouds, Shaheed Minar, player boat, seated captain, rowing paddles, student avatars, debris and docking geometry.

The web runtime uses WebGL 1. Most core missions retain equivalent rules and constants (pickup/ride queue, scoring, delivery, deadlines, traffic lights, power restoration, photos and boost).

**Important limitation:** This is **not** a bit-exact port of all 5,404 lines of the desktop Python application. The gameplay implementation in `game.js`, menu/HUD, physics approximation, weather compositing, some character animations, and some visual effects still differ. The Python file remains the reference implementation. Do not describe this web release as an identical copy until those differences have been eliminated and gameplay parity tested.

## Upload to your existing repository

1. Do not delete or alter the Python project folders or the repository README.
2. Open repository `/docs` and upload/replace **all five files** in the enclosed `docs/` folder, not just JS/HTML:
   * `index.html`
   * `styles.css`
   * `game.js`
   * `original-geometry.json`
   * `original-geometry.bin`
3. Commit to `main`; GitHub Pages remains configured for `main` → `/docs`.
4. Open https://theadittyakumar.github.io/CSE423-Computer-Graphics-Journey/ after deployment. Hard-refresh the page.
5. Verify the menu status says **Original game geometry loaded**, then play and inspect the scene.

The new `.bin` and `.json` files **must** be served alongside the JavaScript; uploading only the JavaScript will not work.

- JavaScript passed Node syntax check.
- Browser WebGL rendered a visible 3D game scene with the new original geometry, no reported JavaScript errors.
- Browser interaction tests passed for menu → playing, movement, request acceptance, and pause.
- First-person and third-person scene rendering inspected in a Chromium/Xvfb Mesa WebGL test.

## Further parity work required

The original Python code contains a separate HUD/menu, wave crests, weather effects, full camera collision behavior, character transitions/boarding, physics and event handling. The current browser port is **not yet a complete one-to-one reproduction**. Compare to screenshots or recordings of the original Python executable before publishing as an identical port.

## Regeneration

`tools/export_geometry.py` takes a path to the original Python file, then an output `docs` path. The script is only a development tool; do not upload `tools/` to GitHub Pages. It runs locally on Python with NumPy, intercepting the source's OpenGL draw calls rather than changing its geometry.
